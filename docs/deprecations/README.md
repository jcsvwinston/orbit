# Deprecation Notices

One file per deprecation that Orbit has written by hand. A `// Deprecated:`
marker in the source says *stop using this*; the notice here says *what to use
instead, when the symbol goes away or the behaviour changes, and what breaks
if you ignore it*. Neither half is enough on its own, so the suite requires
both.

## Naming

- `DEP-YYYY-NNN-<slug>.md`, numbered in Orbit's own namespace from
  `DEP-2026-001`. The sibling products number independently, so
  `DEP-2026-001` here and `DEP-2026-001` in Nucleus or Quark are unrelated.
- One notice per decision, not per symbol. A decision that retires a package
  is one notice covering every symbol in it — see
  [`DEP-2026-002`](DEP-2026-002-nucleus-datasource-adapter-leaves.md).

## The format the guard enforces

The suite runs a check over the three products that reads every hand-written
`// Deprecated:` paragraph, joined across line breaks, and requires all of:

1. the paragraph starts with `Deprecated: ` — the Go convention, which is what
   `go doc`, editors and staticcheck's SA1019 read;
2. it names the replacement;
3. it contains the sentence
   `Scheduled for removal in vX.Y.Z, no earlier than YYYY-MM-DD.`;
4. that version is greater than the version the suite manifest pins for Orbit
   — a promise naming a version already published is a contradiction, and it
   fails;
5. it cites a `DEP-YYYY-NNN` id, and the matching file exists in this
   directory.

The same check reads every notice here with `Status: active`, marker or not:
its header names the version and the date in one line — `Earliest removal`
for a symbol that goes away, `Behaviour flip` or `Earliest change` for a
symbol that stays and does something else — the version is greater than the
pinned one, and a notice that names the major is in the suite's closed list of
the major (`quantum/docs/planes/quantum-2.0.md` §3.0).

Generated code is out of scope by construction: markers under a
`Code generated ... DO NOT EDIT.` header are written by `protoc`, and
rewriting them would be lost on the next run.

## Behaviour changes

A behaviour that changes at the major with no symbol going away gets a notice
here too, with `Scope: behaviour` and a `Behaviour flip` line in place of
`Earliest removal`. There is no `// Deprecated:` marker to carry it — the
field stays — so the notice and the godoc of the affected field are the
announcement, and the tests that pin the v1 behaviour are named in the notice
so the change at the major is a diff to them. See
[`DEP-2026-001`](DEP-2026-001-node-identity-bound-to-certificate-by-default.md).

## Removal rules

- **Removals are major-only.** A stable surface is not removed in `v1.x`;
  every open notice here names `v2.0.0`. An Orbit major also moves the rest
  of the suite, so the removal date and the removal release are two
  different questions.
- **A minimum of 90 calendar days of notice**, counted from the suite set
  that first publishes the notice. The date is when the change becomes
  *eligible*, not when it happens.
- **A notice is announced where its surface is read**: the godoc of the
  symbol or field, this directory, and — for a default that changes — one
  WARN at start in the deployment that still relies on it.

## What Orbit does not have

The sibling register in Nucleus pairs each notice with a migration-assistant
specification and a changelog entry. Orbit has neither home:

- there is no `docs/migration_assistants/` tree. The migration guidance lives
  inside each notice's **Migration path** and **Detection** sections,
  detailed enough to act on;
- `CHANGELOG.md` is generated by release-please from conventional commits and
  has no `Unreleased` section to write into. A deprecation is announced here,
  in the godoc, and in the release notes of the minor that carries it.

A notice whose change has landed on the major's branch moves from `active`
to `completed` (a behaviour flip, a configuration negative, a packaging
change) or `removed` (a symbol or package gone), with an `Applied:` line
under its Timeline naming the branch and the date; the guard reads only the
`active` ones.
